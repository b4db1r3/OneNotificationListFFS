# OneNotificationListFFS

## Support

This repository is used for **bug reports** and **feature requests**.

Before opening an issue, please check if someone already reported the same thing. If not, open the right form:

- [Report a bug](https://github.com/b4db1r3/OneNotificationListFFS/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/b4db1r3/OneNotificationListFFS/issues/new?template=feature_request.yml)

Please include enough detail to make the report useful. For bugs, screenshots or screen recordings are especially helpful.

> A GitHub account is required to submit bug reports or feature requests. Reports sent through other platforms will not be reviewed.
